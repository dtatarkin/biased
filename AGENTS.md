# biased

A Python package of various reusable components, helpers, and utilities,
meant to be usable in any Python project.

This file is the repo's single canonical doc — there is intentionally no
`README.md`, so nothing can drift out of sync with it.

## Development

Run `just` to list recipes; `just test` runs the test suite, `just lint`
runs the pre-commit hooks and the typechecker.
